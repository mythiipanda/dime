# Leaderboard

Use when the user asks who leads the league in a stat, scoring title,
per-game versus totals leaders, or top-N lists.

Rate stats (per-game, per-36, percentages, ratings) require minutes
qualifications. Never present a rate leaderboard without a minutes floor,
and never crown an obscure low-minute player as "best" because their
per-game line looks gaudy.

Always state the minutes floor used, in the output, every time. If the
floor changes what the board looks like, show how: the qualified leaders
versus the raw sort, with the difference noted.

Default posture: per-game leaders need a meaningful sample. Totals
leaders need no floor beyond availability, but note games played when
the gap is close — never multiply a per-game average by games to
manufacture a total.

Totals and per-game answer different questions. State which version the
user asked for, and name the other version's holder when they differ.

What NOT to do: never list a two-game 40% three-point shooter as a
shooting leader; never present a qualified board as raw; never compare
totals across different games played without saying so.
